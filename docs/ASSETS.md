# Design assets and generation

User revised the design to modern white/charcoal/cobalt, a simple responsive HTML5 website plus React Native mobile app. The active visual reference is `design/concept-modern-desktop-mobile.png`. `design/concept-desktop-mobile.png` preserves the earlier forest/cream editorial proposal and is superseded.

Built-in Image Gen was used for both concepts and the fictional sample-family portrait. No user personal or financial document was used as an image reference. Original generated files were copied into the project; project code references only bundled workspace assets.

Prompt for active concept: a complete readable desktop backer Discover screen and mobile applicant Home screen for Billionaire Pay, with white #FFFFFF surfaces, #F5F7FB canvas, #111827 charcoal type, #315BEE cobalt accents, DM Sans sans serif, thin borders, simple responsive layout, white sidebar, bill/project discovery tabs, search/category filters, photographic featured bill request with story and progress, pass/save/review actions, impact rail, applicant create-request and status view, bottom mobile navigation. No dark green, cream, terracotta, gold, serif, gradients, decorative blobs, or fake financial returns.

Portrait prompt: recreate the fictional smiling adult Cameroonian woman in indigo/orange wax-print headwrap and dress from the first UI concept, seated with her fully clothed young son in a warm sunlit modest home; hopeful dignified documentary photography, full 4:5 portrait, no UI, words or watermark. This image is illustrative and does not represent a real applicant.

Further sample category photography is bundled by the frontend; see its image module and design README. Sample stories, identities and requests are fictional.
